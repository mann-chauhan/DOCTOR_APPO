## ⚠️ Important Notes

1. **Make sure both servers are running:**
   - Backend on port 5000
   - Frontend on port 3000

2. **If you see errors:**
   - Check terminal for MongoDB connection errors
   - Make sure MongoDB is running (or use MongoDB Atlas)

3. **First time setup:**
   - Register a new account at http://localhost:3000/register
   - Or create admin: `npm run create-admin`
